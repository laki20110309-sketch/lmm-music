# LMM MUSIC 🎧

AIを使って音楽を生成するプロジェクトです。

「どんな動画・コンテンツに使う音楽なのか」を入力すると、
AIがその内容に合った音楽を生成することを目標にしています。

---

## 🎵 現在できること

現在は開発初期段階です。

まずは、

入力した文章
↓
MusicGen
↓
RTX 4060 Ti
↓
音楽ファイル（WAV）

という流れを作っています。

---

## 💻 必要な環境

- Windows
- Python 3.12
- NVIDIA GPU
- CUDA対応PyTorch
- RTX 4060 Ti 8GB

---
